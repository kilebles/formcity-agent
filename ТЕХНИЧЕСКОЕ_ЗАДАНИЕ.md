# ТЕХНИЧЕСКОЕ ЗАДАНИЕ: AI-АССИСТЕНТ

## 1. Общее описание

Telegram-бот для автоматизации анализа внутренних данных компании, хранящихся в формате Excel, и поиска информации на сайте formcity.ru.

## 2. Интерфейс и взаимодействие

- Платформа: Telegram
- Механика: пользователь отправляет запрос в свободной текстовой форме
- Команды: только `/start`
- Графический интерфейс (кнопки) не предусмотрен

## 3. Функциональные требования

### 3.1. Работа с локальными данными (Excel)

- Анализ .xlsx файлов с поддержкой многостраничных документов
- Поиск пустых ячеек, фильтрация по статусам
- Арифметические расчёты: сумма, количество, проценты
- Генерация текстовых сводок на основе найденных данных

### 3.2. Обезличивание данных перед отправкой в LLM

Перед передачей табличных данных в OpenAI API необходимо заменить персональные данные (ФИО клиентов, названия компаний) на обезличенные псевдонимы (`Клиент_1`, `Клиент_2`, …).

- Реализация через регулярные выражения по известным столбцам с персональными данными
- Маппинг «псевдоним → реальное значение» хранится в памяти только на время обработки одного запроса
- После получения ответа от LLM реальные значения подставляются обратно

### 3.3. Работа с внешними источниками

Пайплайн поиска (LLM управляет переходами через function calling):

1. **Excel-файлы** — основной источник, проверяется первым
2. **formcity.ru** — парсинг через httpx + BeautifulSoup4, если данных нет в таблицах
3. **Интернет** — поиск через Tavily API, если данных нет ни в таблицах, ни на сайте

## 4. Критерии приёмки (эталонные запросы)

- «Интересует какие сделки ещё не зарегистрированы по Well Обводный»
- «Посмотри где есть пустые ячейки в столбце дата регистрации ДУПТ»
- «Какие клиенты находятся на регистрации?»
- «По проекту Well Обводный на вкладке Уступки Well найди в столбце Дата рег-ии ДУПТ пустые ячейки»
- «Сколько продано апартаментов в 22 году?»

## 5. Технический стек

| Компонент | Технология |
|---|---|
| Язык | Python 3.12+ |
| Бот | aiogram 3.x (Polling) |
| Таблицы | Polars + fastexcel |
| AI | OpenAI GPT-4o + Function Calling |
| Веб-парсинг | httpx + BeautifulSoup4 |
| Веб-поиск | поисковый API (Tavily) |
| Обезличивание | Регулярные выражения (встроенный модуль `re`) |
